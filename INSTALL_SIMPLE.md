⚡ Installation Supply - 3 ÉTAPES SIMPLES (Windows)
===================================================

## ÉTAPE 1️⃣: Ouvrir Chrome

```
Cliquer sur le logo Chrome sur le Bureau
ou dans la barre d'outils Windows

     [Google Chrome]
          ↓
    L'app démarre
```

---

## ÉTAPE 2️⃣: Aller au site Supply

**Dans la barre d'adresse, écrire:**
```
http://localhost:8000
                  ↓
            Appuyer ENTRÉE
```

**Ou copier-coller ce lien:**
```
Ctrl+L (sélectionne la barre d'adresse)
Puis utiliser: http://localhost:8000
```

---

## ÉTAPE 3️⃣: Installer l'app

### 🎯 Chercher l'icône INSTALLER

**Regarder dans la BARRE D'ADRESSE:**

```
Chrome:
    http://localhost:8000/    [↓ INSTALLER]
    ↑ Barre d'adresse          ↑
                            CLIQUEZ ICI
                            (petit bouton)
```

```
Edge:
    http://localhost:8000/    [+ INSTALLER]
    ↑ Barre d'adresse          ↑
                            CLIQUEZ ICI
                            (petit bouton)
```

### Si vous ne voyez pas le bouton?

👉 **Menu Chrome/Edge** (⋯ en haut à droite)

```
Menu (⋯)
  ├─ [Créer des raccourcis]      (Chrome)
  └─ [Installer cette application web]  (Edge)
          ↓
      CLIQUER
```

## ⚠️ Si ça ne marche pas?

### ❌ L'icône INSTALLER n'apparaît pas

**Solution 1: Attendre**
```
Parfois ça met 3-5 secondes
Attender un peu, puis regarder à nouveau
```

**Solution 2: Vider le cache**
```
Ctrl + Maj + Suppr
     ↓
Cocher "Images et fichiers en cache"
     ↓
Cliquer "Effacer"
     ↓
Retourner à http://localhost:8000
```

**Solution 3: Essayer en mode Incognito**
```
Ctrl + Maj + N
     ↓
Aller à http://localhost:8000
     ↓
Essayer d'installer là
     ↓
Si ça marche → Vider cache principal
```

**Solution 4: Vérifier que tout va bien**
```
Sur le site:
F12 (ouvrir DevTools)
     ↓
Onglet "Application"
     ↓
Vérifier:
  ✓ Manifest → "Status: OK"
  ✓ Service Workers → "Active"

Si rouge = problème → Contacter support
```

## 📱 Test: Fonctionne offline?

### Vérifier que Supply marche sans internet

1. **Ouvrir Supply** (depuis Menu Démarrer)

2. **Ouvrir DevTools** (F12)

3. **Aller à Network tab**

4. **Cocher "Offline"**

5. **Recharger** (F5)

```
Résultat:

✅ Page charge toujours? SUCCÈS!
❌ Page vide/erreur? 
   → Aller en ligne et visiter le site
   → Puis essayer offline à nouveau
```

## ❓ Questions fréquentes

**Q: Pourquoi je ne vois pas le bouton INSTALLER?**
A: C'est normal les 3-5 premières secondes. Le site doit charger le Service Worker. Attendre un peu!

**Q: Ça fonctionne avec Safari/Firefox?**
A: Oui! Mais la UI est légèrement différente. Utilisez Chrome ou Edge pour une meilleure expérience.

**Q: Je peux désinstaller Supply?**
A: Oui, facile!
   → Menu Démarrer → Clic droit Supply → Désinstaller
   → Ou: Paramètres → Applications → Chercher Supply → Désinstaller

**Q: Comment mettre à jour Supply?**
A: Automatique! Chaque fois que vous allez sur le site, Supply vérifie les mises à jour.

**Q: Supply prend beaucoup d'espace?**
A: Non! Moins de 50 MB généralement.

**Q: Je peux l'utiliser sur mon téléphone aussi?**
A: Oui! La même PWA fonctionne sur Android, iOS, et Windows.
