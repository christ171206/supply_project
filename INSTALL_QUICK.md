## 🆘 ÇA NE MARCHE PAS?

```
❌ "Je ne vois pas le bouton INSTALLER"

   1️⃣  Attendre 5 secondes
       Le Service Worker se charge automatiquement
       
   2️⃣  Vider le cache
       Ctrl + Maj + Suppr
       Cocher "Images et fichiers en cache"
       Cliquer "Effacer"
       
   3️⃣  Recharger la page
       F5 ou Ctrl+R
       
   4️⃣  Essayer en mode Incognito
       Ctrl + Maj + N
       Aller à http://localhost:8000
       Réessayer l'installation

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

❌ "L'installation échoue"

   ✓ Vérifier que Windows 10+ est installé:
     Touche Windows + Pause
     Vérifier la version (doit être 10 ou 11)
     
   ✓ Vérifier que Chrome/Edge est à jour:
     Menu (⋯) → À propos de Chrome
     Doit réinstaller automatiquement

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

❌ "Supply ne demarre pas après installation"

   1️⃣  Redémarrer Windows
   2️⃣  Menu Démarrer → Paramètres (⚙️)
   3️⃣  Applications → Applications installées
   4️⃣  Chercher "Supply"
   5️⃣  Cliquer "Désinstaller"
   6️⃣  Réinstaller (Étapes 1-5 ci-dessus)
```
