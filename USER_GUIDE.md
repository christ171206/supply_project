## Première Visite

### Arriver sur Supply

1. Ouvrir navigateur web
2. Aller à: **https://supply.ci** (ou votre URL)
3. Vous verrez:
   - 🛍️ **En-tête avec catégories**
   - 📦 **Produits en vedette**
   - 📊 **Statistiques marketplace**
   - 🏪 **Filtres de recherche**

### Premiers Clics

- ✅ Explorer les catégories (Ordinateurs, Claviers, etc.)
- ✅ Vérifier les meilleurs produits
- ✅ Lire avis clients
- ✅ **Créer compte** pour acheter/vendre

## Créer un Compte

### Pour un Client

**Étape 1:** Cliquer sur **"S'inscrire"** (haut-droit)

**Étape 2:** Remplir le formulaire
```
Nom: Jean Dupont
Email: jean@example.com
Mot de passe: MDP_SecureAvic123!
Confirmer: MDP_SecureAvic123!
```

**Étape 3:** Accepter conditions d'utilisation ✓

**Étape 4:** Cliquer **"Créer mon compte"**

**Étape 5:** ✉️ Vérifier email (vérification)

Vous êtes prêt à acheter! 🎉

### Pour un Vendeur

**Étape 1:** Cliquer **"S'inscrire"** → Cocher **"Je suis vendeur"**

**Étape 2:** Remplir formulaire vendeur
```
Nom complet: Boutique Tech XYZ
Email: contact@boutique.com
Téléphone: +225 07 XXXX XXXX
Adresse: Abidjan, Cocody
Mot de passe: SecurePassword123!
```

**Étape 3:** Soumettre documents
- 📄 CNI ou Passport
- 📋 Licence commerciale (optionnel)
- 💳 Compte bancaire (pour paiements)

**Étape 4:** Attendre approbation admin (24-48h)

**Étape 5:** ✅ Confirmation par email

## Se Connecter

### Connexion Client/Vendeur

1. Aller sur **"Se connecter"** (haut-droit)
2. Entrer email et mot de passe
3. Cliquer **"Se connecter"**
4. ✅ Vous êtes connecté!

1. Cliquer **"Mot de passe oublié?"**
2. Entrer votre email
3. Cliquer **"Envoyer lien"**
4. 📧 Vérifier email (5-10 min)
5. Cliquer lien du reset
6. Créer nouveau mot de passe
7. ✅ Vous pouvez vous connecter

- 📷 Vignettes produits

## Rechercher des Produits

### Requête Simple

1. Cliquer barre 🔍 **Recherche** (haut)
2. Taper: `MacBook Pro` (ou n'importe quel produit)
3. Appuyer **Entrée** ou cliquer 🔍
4. Résultats affichés 👇

### Recherche Avancée

**Chercher par:**
- Nom du produit: `Laptop gaming`
- Marque: `Dell`, `HP`, `Apple`
- Caractéristique: `16GB RAM`, `SSD 512GB`

### Astuces Recherche

| Votre Recherche | Résultats |
|-----------------|-----------|
| `iphone` | Tous les iPhones |
| `écran 27"` | Écrans de 27 pouces |
| `clavier +souris` | Claviers ET souris |
| `laptop -gaming` | Laptops SAUF gaming |

## Gérer le Panier

2. Choisir **quantité** (si souhaité)
3. Cliquer 🛒 **Ajouter au panier**
4. ✅ Confirmation "Ajouté!"

### Voir le Panier

1. Cliquer 🛒 **"Panier"** (haut-droit)
2. Voir tous vos articles

### Modifier le Panier

| Action | Comment |
|--------|---------|
| **Augmenter quantité** | Cliquer **+** |
| **Diminuer quantité** | Cliquer **-** |
| **Supprimer article** | Cliquer ❌ |
| **Vider panier** | Cliquer "Vider tout" |

### Sauvegarder pour Plus Tard

1. Cliquer **"Sauvegarder"** sur un article
2. Retrouver dans **"Mes Favoris"** plus tard

Frais de port:           25,000 CFA (Selon adresse)

## Passer Commande

### Étape 1: Vérifier le Panier

- ✅ Tous les articles
- ✅ Quantités correctes
- ✅ Prix à jour

Cliquer **"Procéder au paiement"**

### Étape 2: Adresse de Livraison

**Choisir adresse existante** OU **Ajouter nouvelle**
```
Nom complet: Jean Dupont
Adresse: Rue de la Paix, Abidjan
Code postal: 225
Ville: Abidjan
Téléphone: +225 07 XXXX XXXX
```

Cliquer **"Continuer"**

### Étape 3: Mode de Livraison

| Option | Délai | Coût |
|--------|-------|------|
| 🚚 **Standard** | 3-5 jours | 15,000 CFA |
| 🏃 **Express** | 24h | 35,000 CFA |
| 🚴 **Samedi** | Samedi | 40,000 CFA |
| 🏪 **Retrait** | 1-2h | GRATUIT |

Choisir → Cliquer **"Continuer"**

### Étape 4: Mode de Paiement

**Disponible:**
- 💳 Carte bancaire (Visa/Mastercard)
- 🏦 Virement bancaire
- 📱 Mobile Money (Orange, MTN, etc.)
- 💰 Paiement à la livraison

Choisir mode → Cliquer **"Continuer"**

### Étape 5: Confirmer Commande

- 📋 Vérifier tous les détails
- ✅ Cocher "Conditions d'utilisation"
- 💳 Suivre les instructions du paiement

Cliquer **"Passer la commande"**

### Confirmation

- ✅ "Commande réussie!"
- 📧 Email confirmation envoyé
- 📦 Numéro de suivi: `#CMD-000123456`

## Laisser un Avis

### Condition pour Laisser Avis
- ✅ Avoir acheté le produit
- ✅ Être connecté

### Comment Faire

1. Allez page produit
2. Scroller jusqu'à **"Avis Clients"**
3. Cliquer **"Laisser un avis"**

### Remplir l'Avis

**1. Donner une note:**
- Cliquer sur ⭐ (1-5 étoiles)
- Survol = aperçu

**2. Écrire commentaire:**
- Minimum 10 caractères
- Maximum 1000 caractères
- Soyez honnête et constructif!

**3. Options (optionnel):**
- ✅ Ajouter photos
- ✅ Vérifier achat
- ✅ Reste anonyme?

### Publier

1. Cliquer **"Publier mon avis"**
2. ✅ "Avis publié!"
3. Apparaît immédiatement

## Gérer Produits

### Créer un Produit

1. Aller **"Mes Produits"** → **"+ Nouveau Produit"**

2. **Infos Basiques:**
   - Nom produit (requis)
   - Catégorie (requis)
   - Description (500 car min)
   - Prix (requis)

3. **Images:**
   - Ajouter principal (requis)
   - Ajouter galerie (optionnel)
   - Glisser-déposer ou cliquer

4. **Stock:**
   - Quantité disponible
   - Stock minimum (alerte)

5. **Détails Avancés:**
   - SKU (code interne)
   - Poids/Dimensions
   - Marque

6. Cliquer **"Publier"**

### Modifier Produit

1. Cliquer ✏️ en face du produit
2. Éditer les détails
3. Cliquer **"Mettre à jour"**

### Supprimer Produit

1. Cliquer ⚙️ (options)
2. Cliquer **"Archiver"** (temporaire)
3. Ou **"Supprimer"** (permanent)

### Statut Produit

- ✅ **Publié** = Clients le voient
- ⏸️ **Brouillon** = Privé, en cours d'édition
- 🔒 **Archivé** = Caché temporairement

## Gérer Commandes

### Voir Commandes

1. **"Mes Commandes"** → Liste
2. Filtrer par status:
   - 🟡 En attente
   - 🟢 Confirmée
   - 📦 Expédiée
   - ✅ Livrée

### Détails Commande

Cliquer commande → Voir:
- 👤 Client info
- 📦 Produits
- 💰 Total
- 🗺️ Adresse livraison
- 📅 Date commande

### Actions Commande

| Action | Description |
|--------|-------------|
| ✅ | Confirmer commande |
| 📦 | Marquer comme expédiée |
| 🎫 | Ajouter numéro suivi |
| 📧 | Envoyer message client |
| ❌ | Annuler commande |

### Exemple Workflow

```
1. Commande reçue → Statut "En attente"
2. Préparer le colis
3. Cliquer "Confirmer" → "Confirmée"
4. Donner à la livraison
5. Cliquer "Expédier" + ajouter numéro suivi
6. Client reçoit → Auto-passe à "Livrée"
```

## FAQ Rapide

### Q: J'ai oublié mon mot de passe?
**R:** Cliquer "Mot de passe oublié?" et suivre les instructions par email.

### Q: Comment annuler une commande?
**R:** Client: Avant paiement, quitter. Après: Contactez support.
Vendeur: Avant confirmation, cliquer "Annuler".

### Q: Où sont mes images produit?
**R:** Aller "Mes Produits" → Cliquer produit → Section "Galerie".

### Q: Comment augmenter mes ventes?
**R:** 
- 📸 Bonnes photos claires
- 📝 Descriptions détaillées
- ⭐ Maintenir bon rating
- 💬 Répondre messages rapidement
- 🏷️ Bons prix compétitifs

### Q: Que faire si client ne paie pas?
**R:** Commande annulée auto après 48h. Vous pouvez bloquer.

### Q: Comment devenir "Top Vendeur"?
**R:** Avoir rating > 4.5⭐, < 2% de retours, réponse < 2h
